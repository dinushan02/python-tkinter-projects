# 🐍 Python Tkinter Projects — Beginner to Job-Ready

A structured, hands-on collection of **46+ Python Tkinter GUI projects**, organized in a progressive roadmap — from your very first `Hello World` window to full-fledged, portfolio-grade desktop applications.

This repository is built to help learners go from **"I know Python basics"** to **"I can build and deploy real desktop applications"**, following clean folder structure, OOP practices, and real-world project patterns used by professional Python developers.

---

## 📌 Why This Repo?

- ✅ Progressive difficulty — no skill jumps, every project builds on the last
- ✅ Real-world project types (POS systems, CRMs, management systems)
- ✅ Clean, meaningful folder structure for easy navigation
- ✅ Each project is self-contained with its own README, code, and (where needed) database/assets
- ✅ Designed to double as a **developer portfolio**

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/python-tkinter-projects.git
   cd python-tkinter-projects
   ```

2. Create and activate a virtual environment
   ```bash
   python -m venv venv
   source venv/bin/activate      # On Windows: venv\Scripts\activate
   ```

3. Install common dependencies
   ```bash
   pip install -r requirements.txt
   ```

4. Navigate to any project folder and run
   ```bash
   cd 01-beginner/01-hello-world-gui
   python main.py
   ```
